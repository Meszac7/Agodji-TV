À remplir par le fondateur. Cochez chaque point, notez vos remarques.

## Comment voir le résultat
- **Captures d'écran** : dossier `docs/recette/captures-etape-1/` (mobile et ordinateur, thèmes sombre et clair).
- **Dans votre navigateur** : possible dès qu'un lien de préproduction existe (comptes Vercel et Supabase, voir LAUNCH_CHECKLIST §2). En attendant, l'application Claude peut afficher un aperçu si elle le propose.

## 1. Ambiance générale
- [ ] L'ensemble évoque une **marque de divertissement premium et cinématographique**, pas un site administratif.
- [ ] La bannière « À la une » donne envie de regarder.
- [ ] Le thème sombre (par défaut) vous convient.
- [ ] Le thème clair est agréable ; la bannière reste sombre comme un écran de cinéma (choix à confirmer).

## 2. Couleurs
- [ ] Le **jaune royal** des boutons principaux vous convient (teinte, intensité).
- [ ] Le **rouge** est bien réservé aux actions critiques (ex. « Dépublier l'épisode »).
- [ ] Les textes sont lisibles sur votre téléphone, en plein jour comme dans le noir.

## 3. Typographie
- [ ] **Figtree** pour les titres et les prix, **Roboto** pour les textes : l'association vous plaît.
- [ ] Les titres de séries en majuscules épaisses vous conviennent.

## 4. Cartes et composants
- [ ] Les **cartes de séries** (format affiche) sont attractives ; les séries « Bientôt » se distinguent clairement.
- [ ] Les **cartes d'épisodes** montrent clairement : Gratuit, prix, Acheté, Inclus dans votre pass.
- [ ] L'**écran d'achat** (aperçu) paraît simple : pass mis en avant, prix clairs, pays de paiement visible.
- [ ] L'**habillage du lecteur** (aperçu) vous plaît : boutons larges, barre jaune.
- [ ] La **barre de navigation mobile** (Accueil, Catalogue, Bibliothèque, Compte) vous convient.

## 5. À garder en tête
- Le logo « Agodjié TV » est un **logotype texte provisoire** ; les affiches sont des **dégradés de démonstration** ; les titres de séries sont **fictifs**. Ils seront remplacés par vos éléments officiels (D-14).
- Le guide de style n'existe qu'en préproduction : il est automatiquement masqué sur le site public.
